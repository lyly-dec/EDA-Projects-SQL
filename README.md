
# Exploratory Data Analysis with SQL

## Overview
This repository contains SQL-based projects focused on **exploratory data analysis (EDA)** using real-world datasets. The goal is to practice analytical querying, extract business insights, and improve SQL skills for data analysis. 
Objectives: 
- Perform data exploration and data quality checks using SQL
- Answer business and analytical questions
- Practice writing efficient SQL queries for data analysis
- Apply SQL techniques used in real-world data analysis

## Projects
### E-Commerce EDA with SQL  
#### **Dataset:** Brazilian E-Commerce Public Dataset (Olist)
#### **Description:**  
This project performs exploratory data analysis on Brazilian e-commerce data to understand customer behavior, order patterns, revenue performance, and retention using SQL.
#### **Business Questions
The analysis answers several key business questions:
- How many orders are placed each year?
- Which product categories generate the most revenue?
- Which city has the highest number of orders?
- Who are the top-performing sellers by revenue?
- What percentage of orders are paid in installments?
- What is the repeat customer rate?
- What share of revenue comes from repeat customers?
- What is the customer retention rate within three months?
#### **Key Analyses:**
##### **Data Exploration**
- Exploring database structure
- Checking available tables and columns
- Understanding dataset relationships
##### **Sales & Revenue Analysis**
- Order volume trends over time
- Revenue by product category
- Seller revenue ranking
##### **Customer Behavior Analysis**
- One-time vs repeat customers
- Revenue contribution from repeat customers
- Customer retention analysis
#### **SQL Skills Used:**
- JOINs and aggregations
- Common Table Expressions (CTEs)
- Window functions
- Subqueries
- Date and time functions
